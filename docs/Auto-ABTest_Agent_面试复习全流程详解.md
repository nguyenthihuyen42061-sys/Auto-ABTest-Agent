## 步骤 1：样本比例失衡 (SRM) 守门员卡方门禁 (SRM Chi-Square Gate)

### 1. 对应代码位置
- 状态机节点：[`src/agent_workflow.py`](file:///D:/工作/agent开发学习/项目/Auto-ABTest%20Agent/src/agent_workflow.py#L50-L85) 中的 `srm_diagnostic_node()`
- 统计学算法：[`src/stats_engine.py`](file:///D:/工作/agent开发学习/项目/Auto-ABTest%20Agent/src/stats_engine.py#L18-L58) 中的 `check_srm()`
- 条件路由边：`route_after_srm()`

### 2. 为什么这是现代工业界 A/B 实验的“第一红线”？
- **业务痛点与陷阱**：很多初级数据分析师拿到 A/B 实验数据，立刻就去算均值和 $t$ 检验。然而，如果实验系统在分流时出现了**样本比例失衡（Sample Ratio Mismatch, SRM）**，比如原本设计的 $50\% : 50\%$ 分流，实际上实验组只有 $45\%$，这意味着分流不是随机的！
- **严重后果**：极大概率是新版本存在特定机型崩溃、埋点上报时序错乱或网络劫持，从而导致严重的**辛普森悖论（Simpson's Paradox）**。在此情况下直接比较指标均值，得出的结论必定是南辕北辙的虚假结论！

### 3. 底层数理推导与算法
- **统计检验模型**：皮尔逊卡方拟合优度检验（Pearson's Chi-Square Goodness-of-Fit Test）。
- **假设设定**：
  - 原假设 $H_0$：实际入组样本比例与预设理论分流比例一致（例如 $p_c = p_t = 0.5$）。
  - 备择假设 $H_1$：实际入组比例与理论比例存在显著偏差。
- **公式推导**：
  设总样本量 $N = n_c + n_t$。对照组和实验组的理论期望频数分别为：
  $$E_c = N \cdot p_c, \quad E_t = N \cdot p_t$$
  计算卡方统计量（自由度 $df = 2 - 1 = 1$）：
  $$\chi^2 = \sum_{i \in \{c, t\}} \frac{(O_i - E_i)^2}{E_i} = \frac{(n_c - E_c)^2}{E_c} + \frac{(n_t - E_t)^2}{E_t}$$
- **参数标准**：
  - 工业界惯例设定显著性水平 $\alpha = 0.01$（更严苛，避免因为样本量极大而过度频繁误报）。

### 4. 智能体条件路由逻辑
- **分支 A（$\chi^2$ 检验 $p < 0.01$）**：判定触发 SRM 严重异常！
  - 标记 `aborted = True`；
  - 记录详细归因诊断；
  - 状态机通过 `route_after_srm` **直接跳过中间所有检验节点**，直达报告节点输出【红色阻断警报】与产研排查指引！
- **分支 B（$\chi^2$ 检验 $p \ge 0.01$）**：判定分流正常，无系统性偏差，安全流转至步骤 2。

## 步骤 2：数据分布前提自适应诊断 (Distribution Diagnostic)

### 1. 对应代码位置
- 状态机节点：[`src/agent_workflow.py`](file:///D:/工作/agent开发学习/项目/Auto-ABTest%20Agent/src/agent_workflow.py#L94-L126) 中的 `distribution_diagnostic_node()`
- 统计学算法：[`src/stats_engine.py`](file:///D:/工作/agent开发学习/项目/Auto-ABTest%20Agent/src/stats_engine.py#L59-L126) 中的 `check_normality()` 与 `check_homoscedasticity()`

### 2. 步骤核心目标
经典参数检验（如双样本 $t$ 检验）对输入数据有两个铁打的数学假设前提：**正态性（Normality）** 与 **方差齐性（Homoscedasticity）**。智能体必须自主检验这两个前提是否成立，作为下游推断算法自适应选型的严密依据。

### 3. 具体算法与数学推导

#### A. 正态性检验（Normality Test）
系统根据样本容量 $N$ 自动切换最鲁棒的算法：
1. **大样本模式（$N \ge 5000$）**：采用 **D'Agostino-Pearson Omnibus 综合检验**。
   - 分别计算样本偏度（Skewness, $s$）与超额峰度（Kurtosis, $k$）：
     $$s = \frac{\frac{1}{N}\sum (X_i - \bar{X})^3}{\left(\frac{1}{N}\sum (X_i - \bar{X})^2\right)^{3/2}}, \quad k = \frac{\frac{1}{N}\sum (X_i - \bar{X})^4}{\left(\frac{1}{N}\sum (X_i - \bar{X})^2\right)^2} - 3$$
   - 将其转化为标准正态变量 $Z_1(s)$ 与 $Z_2(k)$，构造服从卡方分布的统计量：
     $$K^2 = Z_1(s)^2 + Z_2(k)^2 \sim \chi^2(2)$$
2. **中小样本模式（$N < 5000$）**：采用 **Shapiro-Wilk 检验**（基于正态分位数回归斜率平方与方差之比 $W$）。
- **判定标准**：显著性水平 $\alpha = 0.05$。若 $p \ge 0.05$，判定符合正态性；若 $p < 0.05$，判定为长尾偏态分布。两组分别独立诊断。

#### B. 方差齐性检验（Homoscedasticity Test）
采用 **Levene 检验的 Brown-Forsythe 稳健变体**。
- **为什么不选传统的 Bartlett 检验？** 因为 Bartlett 检验对正态性极度敏感，数据稍有偏态就会严重误判；
- **Brown-Forsythe 创新**：以样本**中位数（Median, $\tilde{X}$）**代替均值作为离差中心：
  $$Z_{ij} = |X_{ij} - \tilde{X}_i|, \quad i \in \{c, t\}$$
  通过对绝对离差 $Z_{ij}$ 进行单因素方差分析（ANOVA），检验两组离散程度是否相等。
- **判定标准**：$\alpha = 0.05$。若 $p \ge 0.05$，接受方差齐性原假设（$\sigma_c^2 \approx \sigma_t^2$）；若 $p < 0.05$，判定存在显著异方差。

## 步骤 3：自适应推断路由、效应量与 Bootstrap 验证 (Adaptive Inference & Effect Size)

### 1. 对应代码位置
- 状态机节点：[`src/agent_workflow.py`](file:///D:/工作/agent开发学习/项目/Auto-ABTest%20Agent/src/agent_workflow.py#L128-L166) 中的 `hypothesis_test_node()`
- 算法引擎：[`src/stats_engine.py`](file:///D:/工作/agent开发学习/项目/Auto-ABTest%20Agent/src/stats_engine.py#L128-L250) 中的 `run_adaptive_ab_test()`

### 2. 智能体自适应决策矩阵（核心亮点）
智能体根据步骤 2 缓存在全局状态中的布尔标记，自主选择最匹配的推断算法：

| 分支条件组合 | 诊断结论 | 智能体自适应选择的算法 | 选型数理依据与容错机制 |
| :--- | :--- | :--- | :--- |
| **正态性 = True 且 方差齐 = True** | 理想标准分布 | **双独立样本 Student's $t$ 检验** | 经典两样本 $t$ 检验，采用合并方差（Pooled Variance）估计标准误。 |
| **正态性 = True 且 方差齐 = False** | 正态但异方差 | **Welch's $t$ 检验** | 采用 Satterthwaite 近似自由度修正，消除异方差导致的第一类错误率（$\alpha$）膨胀。 |
| **任一组正态性 = False** | 长尾偏态（如时长/收入）| **Mann-Whitney $U$ 秩和检验** | 放弃均值假设，转为基于相对排位秩次的非参数检验，完全免疫极端极值干扰。 |

#### Welch's $t$ 检验自由度修正常用公式：
$$\nu \approx \frac{\left( \frac{s_c^2}{n_c} + \frac{s_t^2}{n_t} \right)^2}{\frac{(s_c^2/n_c)^2}{n_c - 1} + \frac{(s_t^2/n_t)^2}{n_t - 1}}$$

### 3. 无量纲标准化效应量：Cohen's $d$ 与业务提升率
- **为什么只看 $p$ 值会犯大错？**
  在大数据时代，只要样本量达到数十万甚至数百万，微不足道的极小差异（例如指标只提升了 $0.001\%$）也会算出 $p < 0.0001$（统计显著），但这在商业上毫无推广价值！
- **Cohen's $d$ 公式**：
  $$d = \frac{\bar{X}_t - \bar{X}_c}{S_{\text{pooled}}}, \quad S_{\text{pooled}} = \sqrt{\frac{(n_c - 1)s_c^2 + (n_t - 1)s_t^2}{n_c + n_t - 2}}$$
- **分级解释标准（Cohen, 1988）**：
  - $|d| < 0.2$：微弱效应（Negligible，即使 $p$ 显著也暂缓推行）；
  - $0.2 \le |d| < 0.5$：小效应（Small）；
  - $0.5 \le |d| < 0.8$：中等效应（Medium）；
  - $|d| \ge 0.8$：大效应（Large，具备极高商业推广价值）。
- **相对提升百分比**：
  $$\text{Relative Lift} = \frac{\bar{X}_t - \bar{X}_c}{\bar{X}_c} \times 100\%$$

### 4. 非参数 Bootstrap 经验置信区间（$B = 2000$ 次重抽样）
- 通过 $B = 2000$ 轮放回重抽样，计算两组均值差的经验抽样分布；
- 构造双侧 $95\%$ 经验置信区间 $[\text{CI}_{\text{lower}}, \text{CI}_{\text{upper}}]$；
- **交叉验证依据**：若置信区间完全不包含 $0$，且与参数检验结论吻合，双重坐实差异的真实有效性。

## 面试高频核心追问速查 (FAQ)

### Q1：为什么你们的 SRM 门禁显著性水平选择 $\alpha = 0.01$ 而不是常规的 $0.05$？
> **答辩金句**：
> “在工业界 A/B 实验场景下，样本量通常达到万级甚至百万级。卡方检验在大样本下具有极高的检验效能（Power），如果采用传统的 $0.05$，微小的随机波动就会导致频繁误报。根据行业规范（如微软与领英的实验平台实践），通常将 SRM 告警阈值设定为更审慎的 $\alpha = 0.01$ 甚至 $0.001$，从而在保证捕捉严重分流漏洞的同时，将假报警率降至最低。”

### Q2：既然已经做了 $t$ 检验，为什么还要费算力去跑 2,000 次 Bootstrap？
> **答辩金句**：
> “这是我们为了确保因果结论稳健性设计的‘双轨交叉验证机制’。$t$ 检验依赖于渐近正态性与大样本极限定理；而实际业务数据往往存在未知的截断、长尾或隐性多峰特征。通过非参数 Bootstrap 进行 2,000 次重抽样，直接从样本经验分布中构造置信区间，不依赖任何分布形态先验假设。两者如果结论一致，能极大增强向产研高管汇报上线决策时的数理置信度。”

### Q3：如果用户数据严重偏态，直接做 Log 变换再做 $t$ 检验不行吗？为什么系统要直接切到 Mann-Whitney $U$ 检验？
> **答辩金句**：
> “这是一个非常经典的统计工程权衡。对数变换 $\log(X)$ 虽然能将部分右偏数据拉近正态，但存在三大致命缺陷：一是如果数据存在大量 0 值（如未购买用户的消费额为 0），$\log(0)$ 在数学上未定义，人为加 1（$\log(X+1)$）会人为扭曲小数值区间的分布结构；二是经过对数变换后的均值差反映的是‘几何均值差异’，在业务汇报时丧失了直观的量纲可解释性；因此，系统选择原汁原味的 Mann-Whitney $U$ 秩和检验，直接比较中位数与概率优势，稳健性更强且结论零失真。”

### Q4：你们的大模型在这个流程中到底起到了什么作用？如果不需要大模型，这些步骤又是怎么实现的？
> **答辩金句（极其严谨且体现架构深度的版本）**：
> “这是一个非常经典的‘神经-符号双模架构（Neuro-Symbolic Architecture）’设计：
> 
> 1. **在离线确定性模式下（零 API / 无大模型）**：
>    - **业务意图与假设**：通过 Pandas 数据模式自省（Schema Introspection）与前端交互式槽位绑定（Slot Filling）实现，避免大模型幻觉编造不存在的字段；
>    - **SRM 故障排查与归因**：由系统内置的‘工业级专家经验规则库’驱动，卡方门禁一旦触发，自动输出标准的三大工程排查指引（客户端 Crash、埋点时序倒挂、分流哈希碰撞）；
>    - **商业决策建议**：通过确定性因果断言逻辑（结合显著性 $p < \alpha$、效应量 Cohen's $d$ 及均值差符号）直接输出全量上线或观望迭代结论。
> 
> 2. **在在线大模型增强模式下（配置 API）**：
>    - 智能体会在节点 5 中将前序步骤生成的**全量结构化计算结果（包括卡方统计量、正态性偏度、方差比、p值、效应量及置信区间）完整打包为一个结构化 JSON 上下文**，发送给大模型；
>    - 大模型扮演‘首席数据科学家’角色，其核心价值在于**将冰冷的离散统计指标融会贯通**，生成兼顾统计学严密性与商业战略视角的定制化高管叙事，并能结合具体业务背景提供更具纵深的因果归因与长期效应分析。
> 
> 这种‘计算由 SciPy 严格断言，规则由专家库兜底，叙事由大模型升华’的分层架构，既具备工业级绝对的高可用防崩能力，又兼具大模型的高维认知表达力。”
